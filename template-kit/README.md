## Get started

```bash
npm install
npm run dev
```

Open http://localhost:3000. The whole page lives in `src/app/page.tsx`; each section is its own component near the top of that file, so you can reorder, edit or delete sections freely.

## Deploy

Push to GitHub and import the repository on Vercel, Netlify or any host that supports Next.js.

## Working with an AI assistant

`AGENTS.md` describes the design system and conventions for Claude, Cursor and similar tools. Ask for changes like "add a testimonials section that matches the design" and point the assistant at that file.
